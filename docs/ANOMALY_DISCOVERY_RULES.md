# 异常发现规则与设计说明

更新日期：2026-09-12。

## 判定目标

本次把“异常发现”统一为：**形变速率幅值大、累计形变量幅值大、方向一致，且在空间上形成聚集的观测点**。结果用于发现值得进一步复核的形变区域。PASC 模式描述变化过程，不能单独使点进入异常结果。

流程为：有效观测 → 双指标交集与方向一致 → 数据质量检查 → 按正、负方向分别聚类 → 输出聚集异常与离散候选。地图强调图层、发现按钮、区域计数和规则摘要应使用同一份结果。

## 参数及其含义

| 参数 | 初始值 | 判定方法 |
| --- | --- | --- |
| 全期速率幅值下限 | 10 mm/yr | `abs(v) >= 10` |
| 末期累计形变量幅值下限 | 30 mm | `abs(d) >= 30` |
| 方向 | 正、负双向 | 正向满足 `v > 0 && d > 0`；负向满足 `v < 0 && d < 0` |
| 空间邻域半径 | 60 m | 同方向候选之间的邻近距离 |
| 核心点最少空间支持 | 5 个不同位置 | 包括核心点自身；同坐标重复记录不能凑足核心点数 |
| 相干性下限 | 0.75 | 已提供的相干性低于下限时排除；明确提供的 0 也属于低质量 |
| 缺测率上限 | 20% | `missingRate > 0.2` 时排除 |

10 mm/yr、30 mm、60 m、5 点是可调整的初始筛选参数，不是经本项目验证的通用工程阈值。实际参数需要结合观测时长、误差、点密度、研究对象和人工复核调整。分位数可用于辅助了解数据分布，不再以“必须选出某个比例”代替实际形变幅度。

默认双向是为了保留正向和负向的大幅变化。正负号是统一后的卫星视线方向约定，不能直接改称垂直沉降或抬升。正负点必须独立形成簇，不能互相凑空间支持，也不能混合平均后相互抵消。

## 时间口径

- 使用已提供的全观测期平均速率；未提供速率且有效观测足够时，按逐点真实日期计算最小二乘年速率。
- 累计量使用数据集选定的共同末期日期 `evaluationDate`。该点没有此日期的真实有效观测时，不用其较早末次值代替，也不填 0；它不能通过本次双指标判定。
- 地图时间轴用于回看过程，不改变本次全期异常判定。当前地图显示值与异常判定末期不同的时候，界面应明确标出判定日期。
- 累计形变量沿用输入数据的参考基准，不把末期值与“最近阶段增量”混为一谈。若以后支持阶段发现，应同时重算同一时间区间的速率和形变量，而不是只移动累计量日期。
- 无时序、末期缺测、非有限数值或无法取得速率的点，不能把占位 0 解释为正常观测。

CSV 空单元格和只有空格的单元格现已解析为缺测。显式填写的数值 `0` 保持有效。每点 `series` 与 `dates` 仍对应真实有效观测，异常判定须按日期查找，不能依靠不同点压缩后的相同数组下标。

上述真实观测口径适用于直接 CSV 解析路径。**浏览器本地 PASC 结果目前把预处理后的序列交给地图**，其中可能已包含插值和平滑；虽然异常模块严格按日期取值，仍不能由该值证明原始日期存在实测。界面和异常 CSV 已增加这一说明，原始观测掩码与模型输入分离仍是下一阶段优先工作。

## 结果分层

1. **聚集异常**：双指标、方向、质量可用性及空间支持均达到当前参数。
2. **离散候选**：幅度、方向和质量可用性达到参数，但未形成同方向密度连通区域。它们保留为复核线索，不计入聚集异常数。
3. **质量受限**：幅度达到参数，但已知相干性过低或缺测率过高。它们不能支撑正式聚集结果，应显示排除数量，便于解释为何结果变少。
4. **质量待核实**：没有提供相干性，或相干性仅为默认占位。可在其余条件成立时参与探索性空间发现，但必须明确质量待核实，不能称为“可靠点”。
5. **观测不足**：缺少有效全期速率、共同末期观测或其他判定必需值，无法完成双指标检查。

质量分层与聚集/离散是两个维度：一个聚集区可以含质量待核实的点。区域详情和交接材料需保留该信息。

空间算法采用带网格索引的密度连通分组。边界点可以连接核心簇，但不能以稀疏长链替代核心密度要求。区域包络只用来定位点群，不代表滑坡边界、单栋建筑、道路路段或危险区。达到浏览器处理上限时，应报告尚未完成聚类，不能将所有未处理点描述为已确认的离散点。

密度邻域和核心点的定义可参照 [scikit-learn DBSCAN 文档](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.DBSCAN.html)；本项目额外按形变方向隔离，并以不同坐标位置计空间支持，避免重复记录堆出密度。该参考不构成本项目默认工程阈值的验证。

浏览器大文件模式的地图点是抽样结果。目前空间发现仍使用地图点集，不能把抽样中的点密度和区域数当成完整文件的空间结果；快速验证同样仅覆盖前若干有效点。界面和导出保留范围提示，后续应把全量空间计算移入本机 Worker，与地图抽样分离。

## 本次修正的设计问题

- 原主按钮使用“速率 ≤ −3，或加速型，或分段型”，累计形变量不参与；模式标签会把幅度很小的点加入结果。现改为双指标同时达标，PASC 仅保留说明。
- 原“重点核查”用另一套负向分位规则，与发现按钮的候选数和地图强调不一致。现统一规则来源，不再让两个入口各自定义异常。
- 原空间聚类只负责对既有异常点分组，离散点也计为异常。现将空间支持作为最终门槛，单列离散候选。
- 原规则只考虑负向，且聚类没有按方向隔离。现支持双向及单方向筛选，并分别建立区域。
- 原相干性判断通过 `coherence > 0` 绕过数值 0；未提供相干性与真实 0 也容易混淆。现按数据来源区分“已知低质量”和“尚未核实”。
- 原 CSV 空白通过 `Number("")` 转成 0，导致缺测率低估、空速率被当作提供值、末期累计量被伪造为 0。现保留真实缺测并添加回归测试。
- 原指标可随时间轴变化而候选选区仍保存旧快照；参数变化时，区域结果、地图点集和摘要必须同步刷新，避免旧选区与新计数并存。

## 公开样本对初始阈值的反馈

对工作区三个公开 CSV 做了只读核算。以下是双幅度阈值与同号通过后的质量分流，**尚未计入空间聚类，不是最终异常数**。拉加镇速率按真实日期拟合；另两个样本使用提供速率。

| 公开样本 | 观测点 / 期数 | 幅度达标且质量可用的负 / 正候选 | 幅度达标但因质量排除 | 可用候选中相干性待核实 |
| --- | --- | --- | --- | --- |
| 新埠岛建筑 | 9,069 / 210 | 9 / 0 | 497 | 0 |
| 拉加镇滑坡 | 11,354 / 58 | 1,837 / 687 | 0 | 2,524 |
| 江东新区道路 | 11,383 / 175 | 1 / 0 | 1,637 | 0 |

核算口径：`abs(v) >= 10`、`abs(d) >= 30`、`v*d > 0`；已提供相干性至少 0.75、缺测率不超过 20%。共同末期分别为 2025-05-03、2022-12-24 和 2024-02-02。道路文件是网页的 25 m 网格样本，不能直接与其全量 27,123 点使用相同点密度解释。

这说明城市和道路示例可能没有足够空间支持形成区域。界面需要展示质量排除的数量和当前参数，允许用户据数据调整；不应为保证演示有结果而自动降低质量标准。此核算只帮助解释默认行为，没有证明默认阈值是最佳参数。

## 后续仍需要考虑的问题

- **全站日期对齐**：已有部分地图渲染、AOI 当前值和 CSV 导出按数组下标取值。在缺测点的日期数组不同的情况下，这些入口仍需系统性改为统一日期查找；本次异常检测固定末期并不能代替全站修复。
- **区域质量与误差**：低相干不是全部误差来源。可在后续加入拟合残差、速率不确定度、时序跳变和共同趋势核查；没有这些字段时不生成伪造置信度。
- **末期值的稳健性**：末期单次观测可能受噪声影响。以后可增加明确的多期持续性或末端窗口稳健累计量方案，并让用户查看原始末期值和采用的统计口径。
- **采样密度与对象差异**：60 m / 5 点在密集建筑、道路网格样本和稀疏坡体上的含义不同。后续可加入背景点密度、邻域异常占比及对象边界，防止仅因采样密集而获得更多空间支持。
- **区域排序**：现有核查排序仍使用固定权重、最大累计量和模式加分。最大值可能受单个点影响，建议后续采用方向分组后的中位/分位幅值、可用质量占比和稳健空间支持，并用人工复核检验排序；排序分值不应解释为经过校准的风险概率。
- **数据语义**：提供的速率必须对应明确的时间范围，累计量必须具有一致的单位、符号和参考基准。导入映射未确认或外部字段本身不一致时，阈值筛选无法自动修复这些语义问题。
