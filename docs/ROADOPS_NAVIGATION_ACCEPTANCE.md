# 滴图自由选点驾车规划：本地验收

更新：2026-09-27。此流程替代原来以 OSM 固定候选和质检结果为起点的规划演示；历史质检功能保留为独立实验，不作为当前驾车功能的前置条件。

## 启动

在仓库根目录运行：

```powershell
# 仅在前端源码改动后重新构建
npm.cmd run build:static
# 提供静态页面和同源驾车 API；保持进程运行
node scripts/serve-roadops-local.mjs --port 4192
```

访问 [本地驾车工作台](http://127.0.0.1:4192/map?demo=road)。也可从任意地图工作台的“驾车”导航进入。

这不是仅托管静态页面的 Vite preview：真实规划还需要上述本地服务。仅绑定 127.0.0.1，不向局域网或公网开放。如果端口已被占用，应确认并关闭原有的该项目预览，不能批量结束其他 Node 进程。

## 配置与用量

- `DIDI_MAP_WEB_SERVICE_KEY` 仅放在已被 Git 忽略的 `.env.local`，不得放入前端环境变量、源码、截图或报告。
- 本次保守配置：本进程每日 HTTP 尝试上限 20，单身份每日上限 20，1 QPS。服务加载或选点不请求滴图。
- 默认保持顺序：坐标转换 + 最终驾车规划，共 2 次上游 HTTP。勾选优化顺序：再增加批量成本请求，共 3 次 HTTP。批量请求内部可能有多个 pack，不等同于官方计费条数。
- 相同点位、顺序、模式、策略在缓存有效期内复用结果；缓存过期后需重新请求。没有自动重试和后台轮询。
- 限额是进程内保护值，重启会重置；不代表滴图账户剩余额度，也不能替代滴图控制台配额及授权管理。
- 可用 `GET /api/roadops/health` 查看配置布尔值、功能范围和本进程计数，不返回 Key。

## 实际操作

1. 点击“在地图上选择起点”，再点击道路附近的位置。
2. 同样选择终点。也可展开“输入精确坐标”，输入 **WGS84 经度、纬度**。
3. 按需增加最多 6 个途经点，全部标为必经。可以删除、重新选点、上下调整顺序，或互换起终点。
4. 默认严格按列表顺序访问；只有勾选“优化途经点顺序”才优化，仍保留全部点。
5. 点击“规划驾车路线”，查看来自滴图的线路、公里数、预计时间和访问顺序。
6. 编辑任一点或策略会移除旧结果，防止展示与当前表单不一致的路线。错误只显示失败和保留选点，不画模拟线、不回退示例路线。

窄屏点选时表单自动收起，完成单次地图选点后恢复。选点时可拖动、缩放地图，Esc 或“取消选点”退出。请求中锁定输入，支持取消等待；已发出的上游请求可能已计入用量。

## 数据边界

- 底图仍是既有 Leaflet/OSM（或用户选定的其他底图），底图道路的显示 **不意味着使用 OSM 算路**。
- 起终点/途经点由用户指定；可行驶道路、路线形状、距离与时间由滴图 Web Service 提供。
- WGS84 输入先用滴图官方坐标转换接口转换；返回几何以近似反算方式与 WGS84 底图对齐，不声称测绘级精度。
- 这是行前规划，不包含实时定位跟随、语音转向导航；现场通行条件以实际标志为准。
- 非商业作品集并不自动免除地图服务授权、署名及缓存约束；继续遵循仓库合规登记，不公开真实服务响应或凭据。

官方技术参考：[驾车与响应模型](https://lbs.xiaojukeji.com/docs/web/guide/%E5%93%8D%E5%BA%94%E6%A8%A1%E5%9E%8B.html)、[坐标转换](https://lbs.xiaojukeji.com/docs/web/guide/%E5%9D%90%E6%A0%87%E8%BD%AC%E6%8D%A2.html)。本项目 6 个途经点是保守的本地限制，不是官方上限。

## 验收清单

| 项目 | 要求 |
| --- | --- |
| 空白起步 | 不自动加载 OSM 质检矢量或固定候选点 |
| 自由选点 | 起、终、途经点均可在地图上任意指定，不吸附至 InSAR 监测点 |
| 请求时机 | 选点、平移和缩放时上游计数不变；只有规划按钮触发 |
| 真实结果 | `provider=didi_web_service`、`mode=didi_live`，展示沿路几何 |
| 输入顺序 | 默认按用户顺序经过全部指定点，不以删点缩短行程 |
| 缓存 | 相同方案再规划显示缓存命中，新增上游请求为 0 |
| 过期结果 | 改点或改策略后旧路线消失 |
| 小屏 | 选点时抽屉收起，完成后恢复，按钮可达 |
| 失败 | 无权限、不可达、额度或超时仅提示错误，不模拟成功 |
| 安全 | 前端产物和 Git 无 Key，本地服务拒绝跨源/私密路径访问 |

自动验证：`node scripts/test-roadops.mjs`、`node scripts/check-roadops-secrets.mjs`。真实浏览器结论记录于 `progress.md`；模拟上游单测不等同于真实配额或路线验收。
