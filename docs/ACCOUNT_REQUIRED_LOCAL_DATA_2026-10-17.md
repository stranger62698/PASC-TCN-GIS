## 访问规则

账号权限与数据处理位置是两项独立政策。登录用于管理产品访问，用户 CSV、时序计算、模型推理及结果仍留在访问者自己的电脑，不上传云端，不创建服务器分类任务。2026-10-16 发布中“本机处理所以无需登录”的结论已于 17 日更正；旧记录仅保留为历史。

| 入口或操作 | 账号要求 |
| --- | --- |
| 默认 `/map`、`/datasets`、`/pasc-local` 及独立本机分析入口 | 先检查会话，未登录展示登录/注册入口 |
| 指定公开 demo：`haikou`、`landslide`、`road` | 可免登录浏览公开数据 |
| 选择或导入自己的 CSV、进入完整数据、本机分析 | 需要登录，包括从公开 demo 发起的用户数据操作 |
| 会话过期后的用户文件操作或继续分析 | 重新登录；同账号可在原标签页继续当前草稿与结果 |

公开 demo 的例外只适用于明确指定的只读案例入口；带上传意图、私有数据/任务、恢复参数或完整数据范围的 URL 不获得该例外。检查会话时不显示已登录，也不允许先打开用户文件选择器或启动分析。

在公开案例中成功授权个人文件操作后，该案例即切为严格登录工作区，CSV、GIS、照片和 JSON 文件均适用。之后即使地址仍带公开 demo 参数，也不再以公开案例例外继续展示个人数据；会话过期时整个工作台不可见，并显示登录门控。

共享会话状态供页头、数据入口和工作台使用，避免各组件重复独立查询。页头显示登录/注册、已登录用户名及退出入口。会话失效时暂停受保护操作；续登保留原标签页的 File、字段映射和已产生的地图结果，不要求通过云端保存继续。更换账号不能继续使用前一账号的受保护工作区。

本机文件与缓存仍按当前电脑、浏览器及网站域名隔离；账号不会将 CSV 和分析结果同步到其他设备。换浏览器、换域名或清理浏览器后需重新选文件，请及时下载结果。超过 1 GiB 的 CSV 先在本机拆成最多 25,000 行、128 MiB 的独立片，再逐片分析；不会转后台处理。

## 服务端账号记录与用量

服务端账号记录包含邮箱 `email`、展示用户名 `name`、创建时间 `createdAt`、账号标识/角色，以及密码哈希 `passwordHash` 和独立盐 `passwordSalt`。密码通过 scrypt 生成哈希，不保存明文密码。

成功认证更新 `lastLoginAt`、`loginCount`。失败状态使用有限字段 `failedLoginAttempts`、`failedLoginWindowStartedAt`、`loginBlockedUntil`，在有限时间窗口内计数和锁定；共享登录/注册限流使用一个固定大小的小计数对象，不为每次请求新增无限审计记录。不保存 CSV 审计、文件内容、完整点集或时序到账号记录。

`GET /api/auth?op=session` 只校验签名会话，不访问 Blob，也不更新账号登录计数。注册和登录会访问账号元数据存储，因此账号服务仍有相应用量。网站页面、模型/WASM 静态资源下载及用户显式触发的滴图规划仍联网；本机 CSV 政策不表示全站离线或零费用。

浏览器门控用于正常产品访问管理，不能保证用户无法修改已下载的前端脚本或自行运行本机计算。登录、驾车等云端服务继续独立执行服务器鉴权、请求校验和额度保护，不能信任前端的“已登录”显示。

## 云数据政策保持关闭

生产构建继续只保留 `api/auth` 和 `api/roadops/driving` 两个函数。私有数据、后台 PASC 任务/Worker、云端推理、外部 AI、语义复核六个 API 不发布函数，由静态 403 `USER_DATA_LOCAL_ONLY` 阻断。登录不会启用这些服务，也不会隐式上传 CSV。

构建及发布必须依次执行 Vercel build、`enforce-local-data-deployment.mjs`、`verify-vercel-output.mjs`、prebuilt deploy；每次重新 build 都需再次 enforce。具体命令和发布后资源检查见 [部署说明](VERCEL_DEPLOYMENT.md)。
