# FP3 实施进度：人工通行核验

更新：2026-10-09。FP3A 四维人工核验、独立历史与本地规划守卫已实现，离线回归通过；浏览器实际操作与业务门待验。**不是整个 FP3 已完成，不构成入口可达或安全认证。**

## 本地入口与验证顺序

[无密钥验收页面](http://127.0.0.1:4193/map?demo=road)。本轮 GET 200；health `configured=false`、`localOnly=true`、`dailyUsed=0`。仅在托管本机进程存活时可用。

4193 与原 4192 的浏览器存储分离，不会自动迁移原端口草稿。未启动原 4192、未读取或更改真实 Key / 用户 100 HTTP 配置；验收实例的进程预算不是账号余额。

1. 顶部“驾车” → “返程与共站任务”，进入完整外业任务编辑器。
2. 在地图点选车辆停靠和核查目标，先保存“任务草稿”。未保存的临时计划可以查看核验项目，但不能追加历史，避免首次保存换 ID 后丢失关联。
3. “通行与入口核验”按对象选择车辆接近、停车许可、入口许可或最后一段进入；总览默认折叠，保持既有蓝字/浅蓝底选择风格。
4. 人工确认须填写核验人、核验时间、有效期限和依据；明确限制须填人、时间和依据。时间输入为中国标准时间 UTC+8，存储为 UTC ISO，不取决于电脑时区。
5. 点击“追加核验记录”才保存；历史只追加、不直接改写或删除。普通未知更新不会解除人工限制。
6. 解除须再次人工确认并显式勾选引用旧限制。每次最多 20 条，剩余限制仍阻断；勾选后的引用固定，重新读取时新增限制不自动列入。解除依据过期或位置变化，旧限制仍保留。
7. 刷新后明确恢复同一任务草稿，读取相同计划 ID 的核验历史；不自动算路。另存副本、导入任务及新计划使用独立核验，原历史仍保留，不套用到新任务。
8. JSON 核验历史独立备份；导出前主动勾选包含精确坐标、核验人和备注的提示。仅含白名单自有数据；有效但保存失败的新记录可随备份保留。无效表单须先完成校验，不承诺无效记录可导出。

## 当前核验规则

| 层级 | 核验项目 | 适用范围 |
| --- | --- | --- |
| 物理车辆停靠 | 车辆接近、停车许可 | 同一个明确 stopId 的所有到访，包括返回；不以坐标相近自动合并 |
| 任务与到访 | 入口许可、最后一段进入 | taskId + visitId；共停车点不同任务不共享入口许可 |

- 缺记录为未核验；过期、相关坐标改变、未来时间或引用证据不可用为待复核。地图商道路成功、道路端点偏移小、历史 legacy confirmed 都不能生成新的人工确认。
- 无依据状态仍可生成“待核验道路规划”，不能展示“核验完成/可安全出发”。完整记录仅显示“人工确认 · 有期限”，不是安全保证、地图商核检或已认证操作者。
- 未解除的人工限制、旧任务明确禁入阻断规划；禁入到期不会自动变成允许。历史对象被移除后保留，但不套用新任务。此为本地工作流约束，不是认证服务端权限控制。
- 最后一段进入方式及人工估计时间目前写在依据内；不生成步行路径，不自动计入分项排程。任务停留仍是人工总时长，最后一段未知在报告保留“未单独估时/总耗时覆盖不完整”。

## 持久化和异步边界

- `roadops-access-check.ts` 严格解析版本、对象、快照、时间和引用；最大 1 MiB、500 条历史、单条最多 20 个引用。仅依据正文允许正常换行，ID/核验人拒绝控制字符。
- `roadops-access-store.ts` 使用独立 IndexedDB；与任务库、照片库分离。revision 由事务维护；已有历史必须保持完整相同前缀，CAS 冲突不覆盖，不将损坏、超时或不可用当成空库。
- `RoadAccessCheckPanel.tsx` 保存/读取/失败时保持表单挂载；未保存表单禁止编辑或切换草稿。草稿 IO 先通知父面板，再禁核验输入，防另存副本等待期间换 ID 丢失表单；旧计划写入结束后再读取新计划，晚到结果不跨计划发布。
- 精确坐标快照绑定依据；表单期间坐标变动不能在提交时偷偷重绑。重置/切换对象需确认放弃未保存内容；刷新有未保存提示。
- `RoadFieldTaskPanel.tsx` 在首个 await 前锁定规划。在编译/发送滴图前重新读历史；响应绑定前再次读历史。读取失败或新增限制不采纳回包，已发出的请求可能已计入用量；不自动重试。
- 备注、核验人、许可依据不进入滴图请求。供应商路线、时距和路况仍仅在内存，未新增其持久化或导出。备份同计划双 ID 校验，不显示或导出其他计划历史。
- 页面仅展示最近 20 条历史，全部记录仍在本机及完整 JSON；没有云同步、备份导入或照片复制。导出成功与文件可打开的真实点击验收仍待补。
