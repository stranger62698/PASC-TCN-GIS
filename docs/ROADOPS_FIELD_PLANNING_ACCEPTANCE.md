# 小客车外业规划：本地验收与使用边界

日期：2026-09-27。基于原平台扩展，不部署、不推送。

## 本轮解决什么

用户需求是能看懂沿哪条道路走、每站如何安排、能否接近核查目标，而不是把点连接后只给总长度。本轮沿用 Leaflet 显示底图，寻路仍由滴图 Web Service 提供；未用 OSM 道路图代替滴图算路。

1. 相邻到访点各取得独立真实道路折线。点击分段卡片可缩放、高亮，折线上箭头标示行驶方向。任何一段失败均不补直线。
2. 核查目标与车辆到达点分开：可直接地图点选或输入 WGS84 经纬度。二者的琥珀虚线只表示直线差距，不是步行或可通行路线。
3. 展示每段里程、预计耗时、接口返回的路况分段距离和参考收费；未返回的字段标为未知。
4. 本地计算到达/离开时刻、核查停留、转移时间、机动缓冲、结束时间与工时超限。出发时刻只是排程输入，不是对该时段路况的预测。
5. 各点进入条件默认为未核实；人工确认须填写依据，人工禁入会阻断。道路端点偏离超过 50 米只触发复核，不把吸附偏移误当作确认可达。
6. 可选关联平台 InSAR 候选、现场照片及滑坡要素中心点，按距真实折线/核查点 100 米筛选。默认关闭；最多评估前 200 条，有截断提示。示例、缺时间、过期记录均不能作为当前封路事实。
7. 下载 TXT 任务单，含逐段行程、坐标、进入核验与待办，不导出地图商完整几何或凭据。

## 操作与验收

本地入口：<http://127.0.0.1:4192/map?demo=road>。

| 操作 | 应观察到的结果 | 实测 |
| --- | --- | --- |
| 地图选起终点、途经点，另设车辆到达点 | 保留目标，不吸附为 InSAR 点；未点规划前无 API 请求 | 通过 |
| 三点按序规划 | 两段真实沿路折线，逐段时距/路况，方向箭头 | 通过真实接口 |
| 点击一段 | 放大、选中段高亮，其他段淡化 | 桌面/390px 窄屏通过 |
| 车辆到达点距目标较远 | 显示直线缺口，不编造步行时间 | 测试约 1394 米，通过 |
| 返回道路端点偏移较大 | 提示车辆位置需复核，不能声称可进入 | 测试约 94 米，通过 |
| 工时改 60 分钟 | 超时阻断，路线保留，不新增 API | 通过 |
| 手工标记不可进入 | 状态变为存在执行阻断项，不被算路成功覆盖 | 通过 |
| 恢复未知状态 | 仍待核验，不能变为已安全可达 | 通过 |
| 相同输入立即再次规划 | 缓存命中，新增 HTTP / route packs 均为 0 | 通过 |
| 下载任务单 | 实际生成本机 TXT 文件 | 通过，已读取文件验证内容 |

真实测试使用同一组三个公开地图位置；第二次因用户恢复工作时原结果已超过缓存期而重新获取当前路况。总共新增 4 次上游 HTTP（每次坐标转换 + 批量算路各 1 次），共 4 个最终算路 packs。未做真实多点顺序优化压力测试，不将模拟覆盖当作真实测试。

最新该测试路线约 25.54 公里、驾车 48 分钟（向上取整），停留 20 分钟、机动 30 分钟，预计总计 98 分钟。实际数字随路况变化，仅作接口联调证据，不是用户最终出行方案。

## 额度与隐私

- 地图平移、选点、分段查看、编辑核验备注、改停留/时间与下载均不请求滴图。
- 手动按序规划：一般 2 次上游 HTTP；优化顺序一般 3 次；一次 HTTP 中可能含多个 route packs。HTTP 次数不是官方计费单位。
- 服务端缓存与计数当前为单进程内存状态，重启会重置，不可据此保证账号日额度。官方额度/计费以控制台为准。
- 升级前本地 health 观察到 10/20，故新启动进程临时将预算收紧为 10，未更改 `.env.local`。最终本进程 4/10，余 6。不能把它描述为滴图账号余额。
- Key 仅服务端读取；入口核验备注不发送给滴图；不把地图商轨迹提交到 OSM 或公开数据集。
- 非商业用途不等于免除授权义务。供应方展示/缓存许可、底图许可及公开发布门禁仍适用。

## 数据能力边界（不能当作已完成）

- 无额外现场资料，因此没有确认现场封路、禁入、合法停车、园区许可、坡度、路面承载及限高限宽；不能声称安全通行。
- 滴图本次使用的公开 `RoutePlanRoute` 提供 `dist`、`duration`、`geo_list`、`segments`、`cost` 等，但未提供路名/逐路口转向口令。箭头表示道路几何方向，不等于左右转导航。
- 没有语音、实时定位、偏航重规划；驾驶时不应操作本网页。到达点附近及最后进入路径须现场核验。
- 输入是 WGS84；服务端使用滴图坐标转换，返回轨迹近似反算到 WGS84 底图。偏移阈值不是测量精度或进入许可判定。
- 30 分钟后本地提示路线时效待复核，不自动刷新耗费额度。即使未过阈值，也不保证路况未变。
- 邻近 InSAR/照片不是封路证据；滑坡面目前按中心近似，可能漏掉靠近面边缘的路线；导入时间不当作采集时间。未命中不代表无风险。
- 核验、排程目前在本次页面会话中，刷新需重新输入。请先下载任务单；不宣称具有完整外业工单同步或离线导航能力。
