# GIS 工作台导航与工具布局整改规划

日期：2026-09-06  
状态：待实施规划；本次仅新增文档。  
参考方向：以百度地图、地球在线的地图优先布局为主要参考，以 ArcGIS、kepler.gl 的专业功能分类为补充。

## 1. 推荐结论

建议从现在的“多处悬浮按钮 + 右侧三类抽屉”，调整为：

**紧凑顶部工作台导航 + 左上数据入口 + 右上地图操作条 + 单一右侧任务面板 + 底部时间轴。**

网站介绍导航与地图工作台分开。数据选择、地图显示、分析任务、核查记录、结果输出各有明确归属。地图角落只保留必要控件，关闭状态的工具不再占用大卡片。

结合用户补充的百度地图、地球在线参考，最终推荐将“数据、图层、分析、核查、导出”五类放到地图页顶部横向排列，**取消右侧“工作区 / 分析 / 工具”竖向导航**。右侧保留用于显示任务详情的抽屉，而不是再复制一套一级导航。这比仅将原来的三个竖按钮改成五个更能减少杂乱。

用户主线：选择数据 → 浏览地图 → 选点 / 选区 → 分析 → 核查 → 导出。

## 2. 审查依据与范围

已检查用户两张截图，并核对当前本地源码：SiteShell.tsx、site.ts、MapWorkspace.tsx、WebGisMap.tsx、AnalysisModeSwitch.tsx、InspectionActionPanel.tsx、globals.css 等。

截图与源码存在少量标题差异，例如截图“常用操作”在当前源码中为“地图工具”，因此以功能和回调为主要依据。本次没有修改现有业务代码。

参考网页已尝试访问：地球在线能读取页面功能与操作指南；百度地图能检索到搜索、工具箱、账户、地图模式等页面内容，但动态页面没有取得可用的完整视觉快照，浏览器工具初始化亦失败。因此不声称已完成两站当前版本的逐像素视觉审查。下文空间排布是结合参考方向提出的本项目设计建议，实施前需补一次实际浏览器对照。

附件文字仅作为现状证据，不视作操作指令。截图中的粉色悬浮控件来源未确认，先在无扩展浏览器中复核，不直接当作产品按钮删除。本文尺寸与验收指标是建议目标，不是已测数据。

## 3. 现状问题：不是数量，而是分类层级混乱

| 区域 | 当前功能 | 问题 |
| --- | --- | --- |
| 网站顶部 | 首页、形变地图、区域统计、案例、产品能力、项目实践、语言、AI 配置、账户 | 宣传内容、业务结果和设置混为一级入口 |
| 地图左上 | 数据标题、状态、观测范围、点数 | 有价值但面积偏大，与数据面板重复 |
| 地图上中 | 卷帘卡片 | 未启用时也强占视觉中心 |
| 地图左下 | 图例、点大小、速率阈值、显示模式、发现异常 | 图例解释、样式、筛选和执行分析混放 |
| 右侧导航 | 工作区、分析、工具 | 工作区和工具概念过宽，无法预判功能去向 |
| 工作区 → 数据 | 案例、导入、规范、教学 Demo、报告、边界说明、同步状态 | 操作与说明同权，大按钮和卡片层层堆叠 |
| 工作区 → 图层 | 底图、业务图层、核查线索比例、图源配置 | 可见性与分析规则混放 |
| 工作区 → 现场 | 现场记录 | 应与核查候选、交付证据相邻 |
| 工作区 → 筛选 | 模式筛选、异常发现、色带、阶段速率、相干性阈值 | 将改外观、限制对象、计算指标放在同一分类 |
| 分析面板 | 点位、区域、交付、AI、PASC | 对象、方法和流程阶段混列 |
| 工具面板 | 统计、截图、规则摘要、报告、导入 CSV | 输入、分析、说明、输出混放；重复入口明显 |
| 底部 | 时间轴、坐标、缩放、署名 | 分区方向合理，但日期与分析区间语义需要统一 |

核心问题实例：

- 调整色带需要进入“筛选”，名称不符合预期。
- CSV 导入同时出现在数据页和工具菜单。
- 区域统计同时出现在网站导航、工具菜单、区域结果。
- “发现异常”同时出现在左下、筛选页及结果中的后续动作。
- “PASC 模式”地图显示与“PASC”运行面板相邻但语义不同。
- “分析控制”面板内放着数据说明和现场记录，标题无法概括内容。

重复入口并非全部有害：区域结果中的“查看完整统计”、点位结果中的“导出此点”属于合理就地动作。应去掉重复的全局功能菜单，保留带有明确对象的捷径，并让它们共用状态和处理函数。

## 4. 如何参考百度地图和地球在线

| 参考 | 可核验内容 / 参考方向 | 本项目采用方式 |
| --- | --- | --- |
| 百度地图 | 页面内容区分搜索、工具箱、账户与地图模式；用户指定其排布作为参考 | 借鉴地图优先和分组入口思路：左上管理当前对象，顶部组织任务，详情按需展开 |
| 地球在线 | 页面提供地名搜索、经纬度定位、地图源切换、测距与分享；操作指南说明地图显示模式位于右上 | 右上集中“怎么查看地图”，把底图、显示、卷帘安排在同一带状区域 |
| ArcGIS Map Viewer | 内容管理与配置分工；图层设置依赖当前图层 | 数据、图层样式、分析条件明确分开 |
| kepler.gl | 围绕数据、图层、筛选组织操作；过滤条件具有数据集作用域 | 筛选单独归类，说明影响哪些点与结果 |
| Terria 工作台 | 数据目录与已添加数据的控制分开 | 案例选择与当前数据详情分开，减少重复说明卡片 |

本项目不需要百度地图的公交、路线、生活服务，也不需要照搬地球在线的全部链接。借鉴的是位置职责和渐进展开方式。暂不增加地名搜索服务、测距、收藏等尚未核实的能力，以免为了参考而扩大开发范围。

## 5. 顶部导航规划

### 5.1 网站内容页

建议顺序：

品牌 | 首页 | 案例展示 | 产品与应用 ▾ | 项目实践 | [进入工作台] | 语言 | 账户

- “产品与应用”包含现有 /platform 和 /solutions。
- “进入工作台”指向 /map，作为网站主要行动。
- “区域统计”移出网站一级导航，保留 /statistics 路由。
- “形变地图 → 点位分析”不再重复跳向同一路由；分析类型在工作台内选择。
- “AI 配置”归 AI 解读内部，不再作为全站高权重按钮。
- 账户菜单保留“我的数据”，公开示例不增加登录门槛。

### 5.2 地图页：工作台专用页头

建议顺序：

品牌 / 返回网站 | 数据 | 图层 | 分析 | 核查 | 导出                         帮助 | 语言 | 账户

顶部五项职责固定：

| 入口 | 回答的问题 | 展开方式 |
| --- | --- | --- |
| 数据 | 正在看哪份数据？怎么导入或切换？ | 打开左上数据面板 |
| 图层 | 显示哪些内容？怎样设置样式？ | 打开右侧图层面板 |
| 分析 | 对点或区域做什么分析？ | 打开右侧分析任务列表 |
| 核查 | 哪些对象要核查？已有何种现场证据？ | 打开右侧核查面板 |
| 导出 | 要输出哪类材料、哪个范围？ | 打开右侧导出面板 |

当前项高亮；再次点击可收起。右侧不再常驻另一个五项导航。地图页不同时保留完整网站六项宣传导航。

### 5.3 地图左上：紧凑数据入口

默认是一张单行或双行小卡：

当前数据：新埠岛建筑形变 ▾
9,069 点 · 210 期

点击展开数据面板。它是顶部“数据”的同一入口捷径，共用面板与状态。完整日期、数据边界、导入报告放展开后的详情，不挤在默认地图画布中。

可在后续已有能力得到核实后加入点位 ID / 坐标定位；本轮不承诺新增全网地址搜索。

### 5.4 地图右上：统一视图操作条

建议：

显示：速率 / 累计形变 / 形变模式 / 更多 ▾ | 选择 ▾ | 底图 ▾ | 卷帘

- “选择”包含单点、多点对比、矩形、多边形。
- “显示”仅改变渲染表达；运行分类算法属于分析。
- “底图”是图层面板底图设置的快捷入口，复用同一状态。
- 卷帘关闭时只有按钮，开启后才出现左右说明和滑块。
- 不放 CSV 导入、AI 配置、规则摘要和导出报告。
- 若一行过长，显示方式改下拉菜单，不允许自动换行堆成多层工具栏。

右侧任务面板打开时，操作条限定在剩余地图区域宽度内，不覆盖抽屉。布局优先采用地图分区，避免各工具各自 absolute 定位导致碰撞。

## 6. 面板功能树

### 数据面板（左上展开）

1. 当前数据摘要：名称、点数、观测覆盖、来源、能力与质量。
2. 添加 / 切换：公开案例、本地 CSV、我的数据。
3. 数据详情：导入与质量报告、数据边界。
4. 帮助：CSV 规范、六类模式教学示例。

规范、教学示例使用文字链接；数据说明默认摘要，展开看详情。“数据状态已同步”变成紧凑状态，不占一整张卡片。

### 图层面板（右侧）

1. 图层列表：InSAR 点、质量图层、核查线索、数据范围、业务图层。
2. 当前图层样式：显示属性、分级范围、间距、色带、点大小与已有透明度设置。
3. 底图：图源选择、透明度、地图服务配置。
4. 添加业务图层：复用现有 GIS 图层导入。

核查线索的“显示开关”留在图层；生成线索的比例与规则移到分析。图层顺序拖动等能力若尚未实现，不能在这一轮冒充已有功能。

### 分析面板（右侧）

任务列表：

- 点位分析：单点时序、质量、模式概率、多点对比。
- 区域分析：已选区域摘要、统计、完整统计页。
- 条件筛选：速率、相干性、模式条件及生效范围。
- 异常发现：候选、固定规则、重点核查线索参数。
- 模式识别：PASC 运行、输入能力与运行结果。
- AI 解读：当前区域摘要、解读、服务配置与依据。

六项采用纵向任务列表或任务选择器，不能把六个长标签塞进一行小页签。进入任务后，面板标题显示任务名，提供返回任务列表入口。

PASC 为方法副标题；Local / Legacy 等执行差异放高级设置，以使用者能理解的方式描述，不占一级导航。

### 核查面板（右侧）

- 核查候选与已有业务对象关联。
- 现场记录、照片、位置和说明。
- 已有核查清单及证据汇总。

整合现有现场记录与 InspectionActionPanel 的相关内容。不要借此新增任务派发、审批流程或组织管理。

### 导出面板（右侧）

- 地图截图。
- 单点 CSV、AOI 点位 CSV 等已实现数据格式。
- 规则摘要、AI 摘要、已有报告。
- 已有核查材料导出。

每项显示输出对象、数据范围和可用条件。若“报告”当前是浏览器打印，则命名“打印 / 保存报告”，不能宣称已经实现独立 PDF 文件生成。

## 7. 逐项迁移表

| 旧入口 | 新位置 | 处理方式 |
| --- | --- | --- |
| 网站顶部区域统计、工具中统计 | 分析 → 区域 → 查看完整统计 | 原路由保留；无选区时说明建立对象方式 |
| 顶部 AI 配置 | 分析 → AI 解读 → 服务设置 | 保留旧深链接映射；不切换当前数据 |
| 左上大数据卡 | 左上紧凑数据卡 + 展开详情 | 观测覆盖与当前显示日期分开 |
| 上中卷帘大卡 | 右上视图操作条 | 开启后再显示说明 |
| 左下显示模式 | 右上“显示” | 更名“地图显示”，与执行分析分开 |
| 左下 / 筛选页发现异常 | 分析 → 异常发现 | 引导与结果中的捷径跳转同一任务 |
| 工具导入 CSV、数据本地分析 CSV | 数据 → 添加 → 本地 CSV | 同一导入流程 |
| 六类 Showcase Demo | 数据 → 教学示例 | 与真实公开案例明确区分 |
| CSV 规范、质量报告 | 数据 → 帮助 / 数据详情 | 用次级文字入口 |
| 筛选中的色带和符号化 | 图层 → InSAR 样式 | 样式表单只保留一份 |
| 图例中的点大小 | 图层 → InSAR 样式 | 图例可提供“编辑样式”捷径 |
| 图例速率阈值、筛选阈值 | 分析 → 条件筛选 | 地图只显示生效条件摘要 |
| 图例类别过滤 | 分析 → 条件筛选的模式条件 | 保留就地点击时，同步状态与计数 |
| 筛选中的阶段速率 | 底部时间轴 → 区间分析 | 明确起止期，不混同当前日期 |
| 图层中负向单侧比例 | 分析 → 异常发现 → 核查线索规则 | 图层只留显示开关 |
| 现场页签 | 核查 → 现场记录 | 保留照片定位和对象关联 |
| 分析交付页签 | 核查内容 + 导出动作 | 候选与证据留核查，输出归导出 |
| PASC 页签 | 分析 → 模式识别 | 与地图“形变模式”渲染区分 |
| 规则摘要 | 分析内查看依据；导出内下载摘要 | 查看与下载使用明确动词 |
| 截图、报告 | 顶部导出 → 对应材料 | 取消常用工具菜单 |
| 数据同步卡 | 底部状态行 | 异常可展开，成功状态简化 |
| 缩放、坐标、署名 | 地图右下与底部状态区 | 避开时间轴与抽屉，署名持续可见 |

注意：固定阈值异常发现与负向分位核查线索是不同规则。统一位置不意味着合并算法或改变阈值含义。

草图表示位置关系，非像素效果图。默认侧面板收起；展开右面板时地图可用宽度收缩，左上数据卡仍为紧凑状态。打开数据面板时关闭右侧任务面板，但保留任务内容。

**任何时刻最多一个大型面板展开**。不要同时展开左侧数据、右侧分析和独立工具窗。

建议尺寸：

- 工作台页头 48–56 px。
- 数据卡宽 260–300 px；视图操作条高约 40 px。
- 右侧任务面板约 340–380 px。
- 底部时间与状态区约 56–72 px。
- 普通正文 13–14 px，辅助说明不低于 12 px。
- 控件圆角约 6–8 px，统一边框、间距和图标尺度。
- 面板白底、细分隔，去掉大蓝色标题块、多重阴影和卡片套卡片。
- 蓝色用于选中状态和主要动作；数据色带不随 UI 配色统一更改。
- 不再使用竖排文字和无信息价值的 WORKSPACE / TOOLS 装饰标题。

## 9. 交互规则与状态约束

1. 关闭面板仅改变可见性，不清空数据、选点、区域或筛选。
2. 单点、多点、矩形、多边形选择由一个互斥状态控制。
3. 卷帘与绘制冲突时退出绘制状态，保留已完成选区；Esc 取消当前交互。
4. 分开“清除选点”“清除区域”“清除筛选”，禁止模糊清除引发连带重置。
5. 区分全量观测覆盖、当前显示日期、阶段速率分析区间。
6. 地图、统计、AI 与导出共用分析上下文；数据或条件变更后旧结果应更新或标记过期。
7. 无时序、无模式、无相干性等情况显示具体不可用原因，不生成虚构结果。
8. 已加载案例默认只看地图；导入意图打开数据；点选打开点位分析；完成框选打开区域分析。
9. 键盘可进入菜单和任务列表，关闭后焦点回到触发控件。
10. 图例保留变量、单位、范围及颜色含义；所有生效筛选有可见摘要。
11. 原导入和导出动作复用现有函数，避免入口重排造成文件范围变化。
12. 处理与失败状态在面板收起时仍可见，成功说明不长期占用地图。
