## 本地复验

1. 打开 <http://127.0.0.1:4192/map?demo=road>，必要时刷新。
2. 切换六个主入口，检查图标、标题、文字颜色与边距。
3. 拖动右侧抽屉左边缘向左展开，向右缩窄，双击复位。
4. 在驾车面板点击选择起点，确认进入地图选点；取消后返回。不点击规划就不会请求驾车接口。
5. 验证路线结果时，明确保留入口未知/阻断、端点偏移和数据边界。

若服务已退出，在项目目录运行 `node scripts/serve-roadops-local.mjs --port 4192`。只监听本地；关闭进程后链接会失效。
