## 保留的能力与边界

1. 滴图 Web 服务提供驾车路线；OSM 等底图只负责地图显示，两者独立。
2. 规划仍由用户手动选择起点、终点与途经点，手动触发。没有自动将形变异常转为出行任务。
3. 道路路线不等于停车、入口或最后一段通行已确认；未知与阻断信息继续保留。
4. 不提供实时定位语音导航，不作工程安全或通行保证。
5. 未修改模型数学、案例点数/期数、地图与科学图表色带、路线请求策略和 100 次本地保护上限。
6. 未移除地图归属信息；“科研与非商业化产品实践”仅说明用途，不代表免除服务许可义务。
